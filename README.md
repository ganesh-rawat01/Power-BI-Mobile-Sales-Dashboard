Mobile Sales Analysis Dashboard | Power BI

Project Overview

This project is an interactive Power BI dashboard designed to analyze mobile sales data and understand sales performance.

Dashboard Features

- Total Sales and Quantity Analysis
- Total Transactions and Average Analysis
- City-wise Sales Analysis
- Monthly Quantity Trends
- Customer Ratings Analysis
- Payment Method Analysis
- Brand-wise Sales Analysis
- Mobile Model-wise Sales Analysis
- Day-wise Sales Trends
- Interactive Filters and Slicers

Tools Used

- Microsoft Power BI

Project Files

- "Mobile_Sales_Dashboard.pbix" – Original Power BI dashboard file.
- "Dashboard_Screenshot.png" – Dashboard preview.
- "Mobile Sales Data.xlsx" – Source Excel dataset used for the analysis.

Key Learnings

- Creating interactive dashboards
- Data visualization
- Analyzing sales performance
- Using charts, cards, maps, and slicers
